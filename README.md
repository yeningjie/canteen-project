\# 校园公共信息与数据展示中心 ——校园食堂看板

\## 项目简介

本项目是面向校园师生的食堂信息看板，实现菜品筛选查询、就餐客流统计、三维食堂场景漫游。纯静态前端，不需要后端服务器。



\## 外部资源

\- Bootstrap5：页面布局、响应式组件

\- Chart.js：柱状图、饼图数据可视化

\- A‑Frame：三维食堂场景渲染

\- jQuery



\## 运行步骤

1\. 将项目文件夹放到本地web服务，例如使用Python http.server或者VSCode Live Server

2\. 浏览器访问 index.html

3\. 导航栏可以跳转菜品查询、客流统计、三维食堂页面



\## 功能说明

1\. 菜品查询：按窗口、菜品类型筛选食堂菜品，无匹配项友好提示

2\. 客流统计：展示窗口就餐人数柱状图，荤素菜品占比饼图

3\. 三维食堂：A‑Frame三维场景，可以旋转缩放浏览，支持返回首页



\## 异常情况

断网或者json文件损坏，页面会提示数据加载异常。筛选无匹配条件显示空数据提示。
